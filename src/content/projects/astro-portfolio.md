# Astro Portfolio

Portfolio personal desarrollado con Astro 4, diseñado para mostrar proyectos y habilidades técnicas de manera elegante y performante. Utiliza las últimas características de Astro como Content Collections y está optimizado para SEO y velocidad de carga.

## Características principales

- **Arquitectura de islas** para máxima performance
- **Content Collections** para gestión estructurada de contenido
- **Modo oscuro** con tema Dracula personalizado
- **Animaciones fluidas** con Framer Motion
- **SEO optimizado** con meta tags dinámicos
- **PWA ready** con service worker
- **Responsive design** mobile-first

## Diseño y experiencia

El diseño está inspirado en el tema Dracula con una estética cyberpunk/hacker:

- **Colores vibrantes** con efectos neon
- **Tipografía monospace** para estética técnica
- **Efectos de glow** en elementos interactivos
- **Transiciones suaves** entre secciones
- **Micro-interacciones** que mejoran la UX

## Tecnologías utilizadas

- **Astro 4** como framework principal
- **TypeScript** para tipado estático
- **Tailwind CSS** para estilos utilitarios
- **Framer Motion** para animaciones
- **MDX** para contenido enriquecido
- **Sharp** para optimización de imágenes

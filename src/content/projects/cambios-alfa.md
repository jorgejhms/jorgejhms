# Cambios Alfa

Plataforma de compra y venta de divisas que combina experiencia de usuario fluida con análisis de mercado en tiempo real. Proyecto que demuestra capacidad de trabajar con sistemas financieros complejos, compliance regulatorio, y visualización de datos.

## Sobre Cambios Alfa

Cambios Alfa se posiciona como socio confiable en operaciones de cambio de divisas, enfocado en seguridad, confianza y accesibilidad. Garantiza transacciones ágiles y confiables con las mejores tasas del mercado.

## Métricas de Impacto

- **14,650+ usuarios activos** en la plataforma
- **2.1M+ transacciones** procesadas
- **$3.4M en capital activo** bajo gestión
- **Regulación SBS** (Superintendencia de Banca y Seguros) cumplida

## Características Principales

### Para Usuarios

- **Conversor de divisas** intuitivo y en tiempo real
- **Histórico de tasas** para análisis de tendencias
- **Múltiples métodos de pago** (transferencia, billetera, efectivo)
- **Confirmación inmediata** de operaciones
- **Soporte 24/7** en múltiples canales

### Para Operaciones

- **Dashboard de administración** con analytics avanzado
- **Sistema de compliance** integrado
- **Trazabilidad completa** de transacciones
- **Reportes automáticos** para reguladores
- **Alertas de fraude** en tiempo real

## Stack Tecnológico

- **Frontend:** Astro, TypeScript, React (para componentes interactivos)
- **Visualización:** D3.js para gráficos de tasas
- **Styling:** Tailwind CSS con diseño consistente
- **Backend:** APIs RESTful para operaciones financieras
- **Base de datos:** PostgreSQL para integridad transaccional
- **Infraestructura:** Hosting en cloud con auto-scaling
- **Compliance:** Integración con sistemas de validación regulatoria

## Diseño y UX

- **Logo inspirado en Cusco** que simboliza solidez y visión de futuro
- **Paleta de colores profesional** que inspira confianza
- **Interfaz clara** que simplifica operaciones complejas
- **Responsive design** funcional en cualquier dispositivo
- **Glassmorphism** en elementos clave para modernidad

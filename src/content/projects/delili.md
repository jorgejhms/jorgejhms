# Delili

Plataforma integral para incentivar el amor por la lectura en niños mediante literatura interactiva y gamificada. Proyecto fullstack que combina contenido educativo, experiencia de lectura inmersiva, y e-commerce integrado.

## Visión

Delili busca transformar la manera en que los niños experimentan la lectura, combinando narrativa tradicional con elementos interactivos que hacen el aprendizaje divertido y memorable.

## Arquitectura del Producto

### 1. Plataforma de Lectura

- **Historias interactivas** con elementos gamificados
- **Personajes recurrentes** que crean conexión emocional
- **Sistema de progresión** que motiva continuidad
- **Interfaz intuitiva** diseñada específicamente para niños

### 2. Tienda de Contenido

- **Biblioteca digital** de historias
- **Sistema de suscripción** para acceso ilimitado
- **Compra de productos físicos** relacionados (libros, merchandise)
- **Recomendaciones personalizadas** basadas en preferencias

### 3. Comunidad

- **Perfiles de usuario** para seguimiento de progreso
- **Sistema de logros** que reconoce avances
- **Interacción entre padres e hijos** en la plataforma

## Características Técnicas

- **SSR/Streaming** con Next.js App Router para experiencia fluida
- **Autenticación OAuth** integrada
- **Base de datos relacional** con PostgreSQL
- **Sistema de carrito** y checkout optimizado
- **Analytics avanzado** para entender comportamiento de usuarios
- **Glassmorphism design** con paleta de colores consistente
- **Responsive design** que funciona en tablets, móviles y desktop

## Stack Tecnológico

- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend:** Node.js, API Routes de Next.js
- **Base de datos:** PostgreSQL con migrations
- **Autenticación:** NextAuth.js
- **Pagos:** Stripe integrado
- **Hosting:** Vercel
- **CI/CD:** GitHub Actions

## Aprendizajes en Proyecto

Este proyecto consolidó mi experiencia en:

1. **Fullstack arquitectura:** Diseño de sistemas que escalan
2. **UX/Design:** Diseñar para audiencia no-técnica (niños)
3. **Business logic complejo:** Suscripciones, progresión, recomendaciones
4. **Performance:** Optimizar para múltiples dispositivos
5. **Testing:** Garantizar estabilidad en plataforma crítica

- Plataforma usada por miles de niños en Perú
- Incremento mensual en usuarios activos
- Feedback positivo de padres y educadores

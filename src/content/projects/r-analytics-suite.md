# R Analytics Suite

Suite completa de herramientas de análisis estadístico desarrollada en R, especializada en análisis epidemiológico y visualización de datos de salud pública. Incluye aplicaciones Shiny interactivas y funciones personalizadas para automatizar flujos de trabajo analíticos.

## Características principales

- **Aplicaciones Shiny interactivas** para análisis exploratorio de datos
- **Funciones personalizadas** para cálculos epidemiológicos
- **Reportes automatizados** con RMarkdown
- **Visualizaciones dinámicas** con ggplot2 y plotly
- **Análisis de supervivencia** y regresión logística
- **Mapas coropléticos** para datos geográficos

## Módulos incluidos

### 1. EpiAnalyzer

Módulo especializado en análisis epidemiológico con funciones para:

- Cálculo de tasas de incidencia y prevalencia
- Análisis de brotes epidemiológicos
- Curvas epidémicas automatizadas
- Tests estadísticos especializados

### 2. DataViz Studio

Aplicación Shiny para visualización interactiva:

- Gráficos dinámicos con filtros
- Mapas interactivos con leaflet
- Dashboards personalizables
- Exportación en múltiples formatos

### 3. Report Generator

Sistema de reportes automatizados:

- Templates personalizables en RMarkdown
- Generación programada de reportes
- Integración con bases de datos
- Salidas en PDF, HTML y Word

## Tecnologías utilizadas

- **R** como lenguaje principal de programación
- **Shiny** para aplicaciones web interactivas
- **ggplot2** para visualizaciones estáticas
- **plotly** para gráficos interactivos
- **dplyr** para manipulación de datos
- **RMarkdown** para reportes reproducibles
- **leaflet** para mapas interactivos

## Impacto

Esta suite ha sido utilizada por equipos de salud pública para analizar datos de vigilancia epidemiológica, generando más de 500 reportes automatizados y apoyando la toma de decisiones basada en evidencia.

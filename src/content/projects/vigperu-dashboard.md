# VigPerú Dashboard

Dashboard completo para la visualización y análisis de datos de vigilancia epidemiológica en Perú. Este proyecto integra múltiples fuentes de datos del Ministerio de Salud (MINSA) para proporcionar una vista unificada de la situación sanitaria del país.

## Características principales

- **Visualización interactiva** de datos epidemiológicos en tiempo real
- **Mapas de calor** para identificar zonas de mayor incidencia
- **Gráficos dinámicos** con filtros por región, fecha y tipo de enfermedad
- **Exportación de reportes** en PDF y Excel
- **API REST** para integración con otros sistemas

## Tecnologías utilizadas

El proyecto está construido con tecnologías modernas para garantizar performance y escalabilidad:

- **Next.js 14** con App Router para el frontend
- **TypeScript** para tipado estático
- **Tailwind CSS** para estilos responsivos
- **Chart.js** para visualizaciones
- **PostgreSQL** como base de datos principal
- **Prisma** como ORM

## Impacto

Esta herramienta ha sido fundamental para mejorar la toma de decisiones en salud pública, permitiendo identificar brotes epidemiológicos de manera temprana y optimizar la distribución de recursos sanitarios.
